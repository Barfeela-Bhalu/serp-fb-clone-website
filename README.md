# serp-fb-clone-website

This is a Facebook website clone that I built to learn and practice the fundamental concepts of Git and GitHub.

The main purpose of this project is not to create a fully functional social media platform, but to understand how version control works in a real development environment. Through this clone, I practiced initializing a Git repository, making meaningful commits, creating and switching between branches, resolving merge conflicts, pushing code to GitHub, and managing the overall project history.

I chose to clone Facebook’s interface because it is familiar and gives enough UI complexity to make the Git practice more realistic. While building the layout, components, and basic structure, I focused on writing clean commit messages and maintaining a proper commit history so that anyone looking at the repository can clearly understand the progress of the project.

This repository is purely educational. It helped me get comfortable with daily Git commands and GitHub workflows that are essential for any developer.
